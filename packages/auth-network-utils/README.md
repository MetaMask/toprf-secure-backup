# `@metamask/auth-network-utils`

common utilities to access and format responses from auth network

## Installation

`yarn add @metamask/auth-network-utils`

or

`npm install @metamask/auth-network-utils`

## Contributing

This package is part of a monorepo. Instructions for contributing can be found in the [monorepo README](https://github.com/MetaMask/toprf-auth-sdk#readme).
